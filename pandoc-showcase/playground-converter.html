Convert a document into a real WordPress page

This is a hands-on migration lab. Upload a source file, let the PHP Pandoc port convert it to WordPress block markup, and inspect the result inside a live WordPress Playground before installing anything or touching a production site.

Showcase Block usage guide
It tests the real import path The file is parsed, rewritten as block markup, imported into WordPress, and opened as an editable page.

It keeps image imports honest Extracted images are uploaded to the media library only when the converted page actually renders an <img> tag for them.

Why this is useful

A static HTML preview can look fine while the WordPress result is hard to edit. This page answers the practical migration question: did the document become structured WordPress content, or did it become a fragile blob?

Can editors keep working? Open the generated page and decide whether the result is structured enough for normal block editing.
Which documents are migration-ready? Try policy PDFs, DOCX reports, Markdown specs, spreadsheets, EPUBs, slides, wiki pages, man pages, and archived formats.
Did images become real media? Check that rendered images were imported and unused extracted files were left out.
Where is the converter weak? Use the live page and log to catch spacing problems, missing images, flattened tables, broken links, or syntax the converter still needs to learn.

What you can do here

  • Smoke-test a migration candidate. Try one representative PDF, DOCX, Markdown file, spreadsheet, EPUB, slide deck, wiki page, or man page before committing to a batch import.
  • Inspect the generated editor surface. Open the created page, edit blocks, move content around, and verify that tables, lists, headings, code, math, links, and captions are still recognizable.
  • Audit media handling. Check the page and media library to confirm that only images used by rendered <img> tags were imported.
  • Turn failures into precise fixes. Use the live output and conversion log to report concrete gaps such as glued PDF words, flattened tables, missing image references, or unsupported syntax.
