Convert a document into a WordPress page

Use this page to answer the question that matters in a migration: can this file become an editable WordPress page, with real blocks and media, without installing anything?

Showcase Block usage guide
It runs the whole import path The document is parsed by the PHP Pandoc port, rewritten as WordPress block markup, imported into a live WordPress Playground, and opened as a page.
It makes the result inspectable You can edit the page, inspect the block structure, check tables and lists, and see whether the content behaves like WordPress content instead of pasted HTML.
It keeps media honest Extracted images are uploaded to the media library only when the converted page actually renders an <img> tag for them.

Upload

Drop a source document here, choose or confirm the input format, and the embedded Playground will create a WordPress page from it.

What you can learn from one upload

A static HTML preview can hide the hard parts of a WordPress migration. This tool shows the real editing surface: blocks, media-library attachments, links, tables, lists, code, math, headings, and the places where conversion still needs work.

Can editors keep working? Open the generated page and decide whether the result is structured enough for normal block editing.
Which documents are migration-ready? Try policy PDFs, DOCX reports, Markdown specs, spreadsheets, EPUBs, slides, wiki pages, man pages, and archived formats.
Did images become real media? Check that rendered images were imported and unused extracted files were left out.
Where is the converter weak? Use the live page and log to catch spacing problems, missing images, flattened tables, broken links, or syntax the converter still needs to learn.

Useful things to try

  • Upload one representative file before planning a larger migration.
  • Edit the generated blocks and check whether tables, lists, and headings survived as real structure.
  • Open the media library and confirm which rendered images were imported.
  • Use the log and page output to create precise bug reports for conversion gaps.
