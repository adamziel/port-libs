Convert a document into a WordPress page

This is a zero-install WordPress import lab. Upload a real document, let the PHP Pandoc port convert it to native block markup inside an embedded WordPress Playground, import only the images that are actually used by rendered <img> tags, and open the finished page immediately. It shows whether a file can become editable WordPress content, not just a pasted blob of HTML.

Turn documents into something WordPress can actually use

Migration tests usually answer the wrong question: "did it render?" This page answers the useful question: "can an editor work with it after import?" Why this is useful

        
Most document converters stop at HTML. This one creates a WordPress page, so you can judge the parts that matter for publishing: editable blocks, media-library files, preserved links, tables, lists, code, math, and document structure.

      


      

        
What you can do

        
    
          
  • Drop in a document and open the converted result as a WordPress page.
    • 
          
  • Edit the generated blocks in the WordPress editor to see what survived as structured content.
    • 
          
  • Open the media library and confirm which extracted images were imported.
    • 
          
  • Test documents that usually break importers, including tables, multi-column PDFs, footnotes, math, code blocks, and embedded media.
    • 
          
  • Compare tricky source files against the showcase output and report conversion gaps.

What happens

        
    
          
  1. The uploaded file is parsed by the port-libs Pandoc readers.
    2. 
          
  2. The document is rewritten as WordPress block markup.
    3. 
          
  3. Referenced rendered images are imported into the Playground media library.
    4. 
          
  4. A new page opens so you can inspect, edit, and publish-test the result.
