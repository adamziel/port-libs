Convert a document into a WordPress page

This is a zero-install WordPress import lab. Upload a real document, let the PHP Pandoc port convert it to native block markup inside an embedded WordPress Playground, import only the images that are actually used by rendered <img> tags, and open the finished page immediately. It shows whether a file can become editable WordPress content, not just a pasted blob of HTML.

Turn real documents into editable WordPress pages

This page is useful because it tests the whole publishing path, not just a standalone HTML preview. You can take a file people already have, run it through the PHP Pandoc port in the browser, and inspect the result inside WordPress as blocks, media-library files, links, tables, lists, code, math, and headings.

See whether import is practical Open the generated page in WordPress and check whether an editor could continue working with it.
Test hard source material Try policy PDFs, DOCX reports, Markdown specs, spreadsheets, EPUBs, slides, wiki pages, man pages, and archived formats.
Verify media handling Images are imported only when they are actually referenced by rendered <img> tags, so unused extracted files do not become media clutter.
Find conversion gaps quickly Use the live page and log to catch spacing problems, missing images, flattened tables, broken links, or syntax the converter still needs to learn.

What you can do here

  • Drop a document and immediately open the converted WordPress page.
  • Edit the generated blocks to see what remained structured instead of becoming raw HTML.
  • Inspect the media library to confirm which images were imported.
  • Compare tricky files against the static showcase output and report specific conversion bugs.
