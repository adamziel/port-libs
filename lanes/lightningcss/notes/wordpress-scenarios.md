# LightningCSS WordPress Scenario

Shared-hosting CSS transforms for themes, blocks, Playground, and plugin build-free delivery.

## Current Native Slice

Native CSS comment/whitespace minifier, declaration block parser, CSSOM-style direct declaration plus margin/padding, logical margin/padding set ordering across physical fallbacks, background, mask-border-source, border, flex-flow, animation-name, grid-area, grid-template, and grid shorthand access, focused animation duration/delay/iteration/fill-mode longhand minification, focused transition duration/delay/timing-function longhand minification, focused transition shorthand value minification, value-level color keyword shortening, math-function operator spacing, a small stylesheet parser that distinguishes style rules, at-rule statements/blocks, declarations, selectors, and nested WordPress rules, selector specificity packing/comparison for override ordering, media query range/feature/list normalization, and a focused `@custom-media` transformer.

`examples/wordpress-stylesheet-parser.php` parses the block-theme CSS fixture and reports the top-level rule count, first selector list, and declaration count. `examples/wordpress-border-cssom.php` models a theme.json-style block border where `border-color` recomposes a full physical border shorthand while side-specific overrides remain guarded. `examples/wordpress-animation-cssom.php` rewrites keyframe animation names from a shorthand while preserving duration/easing/fill-mode tokens, and falls back to a separate `animation-name` list when a block style needs multiple names. `examples/wordpress-animation-longhand-minifier.php` minifies block animation preset longhands so duration/delay values use LightningCSS-style shortest time units and list-valued controls serialize consistently. `examples/wordpress-transition-longhand-minifier.php` minifies block button transition presets, including simple time `calc()` values and common easing aliases. `examples/wordpress-transition-shorthand-minifier.php` minifies block interaction transition shorthands, preserving author intent while canonicalizing property/duration/timing/delay order and omitting default `ease`. `examples/wordpress-logical-spacing-cssom.php` models logical block spacing controls where a later physical fallback must stay in place and a new logical declaration is appended. `examples/wordpress-grid-area-cssom.php` reads row and column placement from a four-part `grid-area` shorthand for block layout migrations. `examples/wordpress-grid-template-cssom.php` extracts explicit block-template area rows, tracks, and initial auto-placement from longhands as `grid-template`/`grid` shorthand values. `examples/wordpress-mask-border-cssom.php` extracts the image source from decorative mask-border declarations used by block or theme frame styles. `examples/wordpress-custom-media-transformer.php` expands block-theme breakpoint and motion aliases from `@custom-media` before minification so shared-hosting tooling can consume modern theme CSS without Node. The declaration helper now exposes background color/image/repeat/position/size CSSOM behavior needed by block background controls and theme style migration tools, mask-border source behavior for decorative frame migration, border shorthand behavior used by block style controls, logical margin/padding ordering behavior for fallback-preserving spacing migrations, prefixed and unprefixed `flex-flow` direction/wrap behavior used by block layout migrations, animation-name updates for keyframe migration tools, animation longhand minification for block style presets, transition longhand and shorthand value minification for block interaction presets, and grid placement/template access for layout tooling. The specificity helper covers WordPress override selectors such as block-button hover styles and ID-scoped navigation rules. The media query helper normalizes responsive block-theme breakpoints such as min/max width aliases, comparison ranges, hover/update features, ratios, and simple same-unit calc values. The custom media transformer maps focused upstream `src/lib.rs::test_custom_media` cases for list substitution, recursive and later declarations, media type factoring, negation simplification, undefined/circular reference errors, and preserving declarations when requested. This gives shared-hosting and Playground tooling a native AST boundary before adding prefixing, bundling, or broader transformer semantics.
