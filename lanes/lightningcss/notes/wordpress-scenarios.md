`examples/wordpress-stylesheet-parser.php` parses the block-theme CSS fixture and reports the top-level rule count, first selector list, and declaration count. `examples/wordpress-border-cssom.php` models a theme.json-style block border where `border-color` recomposes a full physical border shorthand while side-specific overrides remain guarded. `examples/wordpress-animation-cssom.php` rewrites keyframe animation names from a shorthand while preserving duration/easing/fill-mode tokens, and falls back to a separate `animation-name` list when a block style needs multiple names. `examples/wordpress-animation-longhand-minifier.php` minifies block animation preset longhands so quoted keyframe identifiers, reserved keyword strings, easing aliases, duration/delay values, and list-valued controls serialize consistently with LightningCSS. `examples/wordpress-animation-shorthand-minifier.php` canonicalizes a block animation shorthand with a quoted keyframe name, cubic-bezier alias, delay, iteration count, fill mode, and scroll timeline without Node. `examples/wordpress-transition-longhand-minifier.php` minifies block button transition presets, including simple time `calc()` values and common easing aliases. `examples/wordpress-transition-shorthand-minifier.php` minifies block interaction transition shorthands, preserving author intent while canonicalizing property/duration/timing/delay order and omitting default `ease`. `examples/wordpress-transition-composition.php` folds block pagination interaction transition longhands into compact shorthand while preserving list cycling and non-default delay semantics. `examples/wordpress-logical-transition.php` expands block-axis logical transition targets such as `margin-block` into physical top/bottom transition properties for block spacing animations. `examples/wordpress-legacy-transition-prefixer.php` emits legacy Safari transition fallbacks for navigation block spacing animations that combine `margin-inline-start` with `transform`. `examples/wordpress-mask-transition-prefixer.php` emits legacy WebKit transition property names for framed cover block styles that animate `mask-border` and `mask` without Node. `examples/wordpress-mask-border-prefixer.php` composes decorative cover-frame mask-border longhands into compact modern and `-webkit-mask-box-image` fallbacks with sRGB fallback layers before the LCH source layers for shared hosting. `examples/wordpress-mask-border-var-supports.php` emits the upstream-style sRGB base declarations plus lab `@supports` fallback for a cover-frame mask-border whose slice is controlled by a CSS custom property. `examples/wordpress-mask-image-prefixer.php` composes an LCH gradient media-cover mask-image/position/size/repeat/origin/clip/mode stack into sRGB fallback and modern advanced-color `-webkit-mask`/`mask` layers for themes that cannot run a Node build step. `examples/wordpress-logical-spacing-cssom.php` models logical block spacing controls where a later physical fallback must stay in place and a new logical declaration is appended. `examples/wordpress-grid-area-cssom.php` reads row and column placement from a four-part `grid-area` shorthand for block layout migrations. `examples/wordpress-grid-template-cssom.php` extracts explicit block-template area rows, tracks, and initial auto-placement from longhands as `grid-template`/`grid` shorthand values. `examples/wordpress-mask-border-cssom.php` extracts the image source from decorative mask-border declarations used by block or theme frame styles. `examples/wordpress-custom-media-transformer.php` expands block-theme breakpoint and motion aliases from `@custom-media` before minification so shared-hosting tooling can consume modern theme CSS without Node. `examples/wordpress-custom-media-boolean-guard.php` models an incompatible print alias used inside screen styles and surfaces the same native guard as focused upstream custom-media error cases. The declaration helper now exposes background color/image/repeat/position/size CSSOM behavior needed by block background controls and theme style migration tools, mask-border source behavior for decorative frame migration, border shorthand behavior used by block style controls, logical margin/padding ordering behavior for fallback-preserving spacing migrations, prefixed and unprefixed `flex-flow` direction/wrap behavior used by block layout migrations, animation-name updates for keyframe migration tools, animation longhand and shorthand minification for block style presets, transition longhand/shorthand value minification, transition declaration composition, block-axis logical transition expansion, direction-sensitive inline transition prefixing, transform transition prefixing, mask/mask-border transition prefixing, mask-border shorthand/longhand prefix composition, mask-image/mask longhand composition, and focused advanced-color fallback layering including lab `@supports` emission when variables prevent a single advanced-color fallback layer, and grid placement/template access for layout tooling. The specificity helper covers WordPress override selectors such as block-button hover styles and ID-scoped navigation rules. The media query helper normalizes responsive block-theme breakpoints such as min/max width aliases, comparison ranges, hover/update features, ratios, and simple same-unit calc values. The custom media transformer maps focused upstream `src/lib.rs::test_custom_media` cases for list substitution, recursive and later declarations, media type factoring, negation simplification, undefined/circular reference errors, unsupported media-type boolean-logic errors, and preserving declarations when requested. This gives shared-hosting and Playground tooling a native AST boundary before adding bundling or broader transformer semantics.
