# attach-wal-temp-current-next67

- Scope: bounded ATTACH/temp/main WAL prepared-statement lifecycle behavior. Current active statements keep their current snapshot, while reset/next execution observes schema-cookie or object-list changes from temp/main/attached WAL DDL and returns `SQLITE_SCHEMA`/reprepare decisions for the statements that actually touch changed schemas.
- Non-overlap: avoids accepted attach WAL/temp object resolution current-next64, write routing current-next65, schema SQL extraction current-next53, collation cache current-next55, WAL checkpoint/savepoint byte truncation, VFS writer/sync/rollback apply, JSON table source/cursor/hidden/visible constraint work, and B-tree pointer-map/page-move/freeblock clusters. This slice adds statement lifecycle expiry decisions on top of the existing schema-cache planners rather than another object-resolution or write-routing helper.
