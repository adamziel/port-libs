# markerpdf annotations links optional content boundary current-base

- Slice: `markerpdf-annotations-links-boundary-current-base-20260606T115248Z`.
- Source truth: PDF 1.5 annotation dictionaries may carry `/OC` optional-content membership. markerPDF's native searchable-PDF path should follow the same default-view visibility boundary used by PDFium/pdftext-style extraction: annotations on OFF optional-content groups, or OCMD policies that evaluate hidden, must not become WordPress links.
- Implementation: `PdfLinkAnnotationExtractor` now builds catalog `/OCProperties` default-view OCG states, applies `/BaseState`, `/ON`, `/OFF`, `/AS /Event /View` usage-state overrides, and evaluates annotation `/OC` references, direct OCG dictionaries, and OCMD policies before link promotion. Visible links retain review metadata under `optional_content_*` / `link_optional_content_*`.
