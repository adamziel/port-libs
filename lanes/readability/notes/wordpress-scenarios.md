# Readability/content rewrite engine WordPress Scenario

Migration-aware article cleanup into clean WordPress blocks with page-builder navigation, comment widgets, share UI, in-article ad slots, and surrounding theme chrome removed.

## Current Native Slice

Native DOM extractor removes chrome and upstream-style unlikely candidates, removes invisible `display:none`/`visibility:hidden`/`hidden`/`aria-hidden` nodes plus `aria-modal` dialogs while preserving `fallback-image` media, promotes one substantial article out of surrounding body/main wrappers, removes empty paragraphs with no media/embed payload, removes ad wrappers such as `ad-container`, `ad-mobile`, `dfp-slot`, and `js_ad`, removes layout-only full-width figure wrappers while keeping editorial in-column figures, removes one-cell layout table wrappers while preserving multi-cell and upstream-marked data tables, normalizes legacy `font` tags to spans, removes article comments, strips presentational/style attributes from retained article markup, removes interactive article controls and leading byline/follow/read-time/share action bars before the first content heading while preserving avatar media, scores semantic content containers and article-body containers including body-only fallback pages, parses UTF-8 HTML safely, implements Mozilla-style `isProbablyReaderable` thresholds, extracts document titles before in-article headings, uses first paragraphs for metadata-free fallback excerpts, removes duplicate title headings from content, removes scaffold `h1`/`h2` nodes that only surround paragraph-bearing section containers, demotes remaining `h1` body headings to `h2` before block serialization, simplifies nested `div`/`section` wrappers, wraps consecutive phrasing children inside `div` nodes into paragraphs, preserves media-bearing single-paragraph `div` wrappers, converts text/phrasing-only `div` blocks to paragraphs, converts repeated `br` chains into paragraph boundaries while preserving single soft breaks, collapses low-link-density non-media `div` wrappers around a single paragraph, strips source CSS classes during post-processing, resolves relative `href`, `src`, `poster`, and `srcset` URLs against the source document URL and base element, replaces `javascript:` links with inert retained content, gives entity-decoded plain meta descriptions precedence for excerpts, exposes byline/site/published/dir/lang metadata fields from meta tags and JSON-LD, preserves allowed video embeds while removing generic embedded widgets, promotes lazy `data-src`/`data-srcset` images including short base64 placeholder cases, removes post-article recommendation/signup chrome after selected article wrappers, maps Mozilla fixture pages including `normalize-spaces`, `embedded-videos`, `videos-2`, `lazy-image-1`, `lazy-image-2`, `lazy-image-3`, `base-url`, `base-url-base-element`, `base-url-base-element-relative`, `js-link-replacement`, `table-style-attributes`, `links-in-tables`, `keep-tabular-data`, `remove-aria-hidden`, `hidden-nodes`, `visibility-hidden`, `replace-brs`, and `remove-extra-brs`, and emits WordPress paragraph, heading, image, and table blocks while flattening block-only layout containers.
