# External LaTeX Regression Corpus

These standalone fixtures are reduced, attributed extracts from real
open-license LaTeX sources. They are intentionally kept small: the goal is
to exercise parser behavior, not to mirror or redistribute upstream books.
Each extract retains parser-relevant structure and has been normalized only
enough to be independently importable. No upstream binary media is included.
