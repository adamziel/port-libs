# DOCX ZIP source-record package part directory base names

`plib-rlnry` adds metadata-only DOCX/OpenXML ZIP source-record rollups for exact package part directory base names and case-folded directory base names. The summaries carry counts, source-record byte totals, duplicate directory-name buckets, directory roots, part extensions, content-type sources, compression methods, roles, part-name lists, and largest source-record part metadata without exposing package payload bytes.

Focused coverage lives in `DocxOpenXmlZipSourceRecordPackagePartDirectoryBaseNamesTest.php` and registers one mapped manifest case with 63 assertions.
