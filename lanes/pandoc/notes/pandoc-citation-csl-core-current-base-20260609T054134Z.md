## Behavior

- Implemented bounded CSL sort-key name-list overrides for `names-min`,
  `names-use-first`, and `names-use-last`.
- `CslStyle` now preserves and validates those attributes on `cs:key` entries.
- `CitationCslProcessor` now applies the overrides to native name-variable sort
  keys and to macro sort keys while evaluating macro-generated names for sort
  comparison.
- Added a WordPress-facing self-test example showing a citation cluster and
  bibliography whose sort order changes from full name-list comparison to the
  CSL key-declared truncated name comparison.

Source truth: CSL 1.0.2 sorting allows `cs:key` to carry `names-min`,
`names-use-first`, and `names-use-last` to override et-al abbreviation for sort
keys, including names generated by macros:
<https://docs.citationstyles.org/en/v1.0.2/specification.html#sorting>
